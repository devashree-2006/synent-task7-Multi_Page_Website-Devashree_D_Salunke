# ReWear – Sustainable Fashion Website

## Multi-Page Website

ReWear is a responsive multi-page website based on sustainable fashion. The idea is to encourage people to reuse, exchange, donate, and upcycle clothes instead of throwing them away.

## Pages

- Home
- About
- Services
- Contact

## Features

- Responsive design
- Multi-page navigation
- Consistent UI across all pages
- Responsive mobile navigation
- Contact form validation
- FAQ interaction
- Character counter
- Hover effects and animations
- Sustainable fashion services

## Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Project Purpose

The purpose of ReWear is to promote sustainable fashion by encouraging people to give their clothes a second life through reuse, exchange, donation, and upcycling.
